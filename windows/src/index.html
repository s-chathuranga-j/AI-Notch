Personal & work

Claude profiles in your home folder are discovered at startup. For a work account, set $env:CLAUDE_CONFIG_DIR="$HOME\.claude-work" in PowerShell, then run claude and sign in. Restart AI Notch to discover it.

Your privacy

Enable each account explicitly. Claude credentials are read locally and sent only to Anthropic’s usage endpoint. Codex uses its own CLI. Credentials and usage are never saved by AI Notch. No analytics, publisher servers, or automatic updater.

Claude and Codex are supported in this first Windows build. Other providers and live coding activity indicators are not yet ported.
