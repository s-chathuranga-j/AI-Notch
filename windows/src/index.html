Alert at
When a limit crosses a chosen level, or is on pace to run out before it resets, the notch comes out on its own — even in On hover or Hidden mode — then goes back. It comes out once more in green when that limit resets. During quiet hours alerts wait; a limit still high when they end is announced then.

Personal & work

Claude profiles in your home folder are discovered at startup. For a work account, set $env:CLAUDE_CONFIG_DIR="$HOME\.claude-work" in PowerShell, then run claude and sign in. Restart AI Notch to discover it.

GitHub Copilot (experimental)

Sign in with gh auth login using your Copilot account, then enable GitHub Copilot. If GitHub denies quota access, the GitHub CLI login may not have permission for this internal endpoint. You can supply a compatible token through COPILOT_GITHUB_TOKEN before launching AI Notch. Never paste tokens here. VS Code sign-in alone is not read by this app.

Copilot reports available quota percentages and reset dates. Unlimited quotas show Unlimited. GitHub may change or restrict its internal quota endpoint.

Your privacy

Enable each account explicitly. Claude Code’s status line saves usage percentages and reset times locally. AI Notch does not read Claude credentials or send Claude requests. Codex uses its own CLI. Copilot reads a token from the environment or GitHub CLI and sends it only to GitHub’s quota endpoint. The other providers’ readings are kept in memory. No analytics, publisher servers, or automatic updater.

Claude, Codex, and experimental GitHub Copilot usage are supported. Other providers and live coding activity indicators are not yet ported.
